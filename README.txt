JP ASSOCIATE WEBSITE TRIAL

Files:
- index.html: homepage
- about.html: about page
- properties.html: searchable/filterable demo properties
- property.html: reusable property detail page
- locations.html: industrial locations
- contact.html: contact form and map
- styles.css: responsive gold-and-white styling
- script.js: property data, filtering, dropdowns, popup and demo form interactions
- assets/jp-associate-logo.png: supplied/generated JP Associate gold logo

How to preview:
1. Extract the ZIP.
2. Open index.html in a modern browser. For best results, use a simple local server or VS Code Live Server.
3. Images are loaded from remote Unsplash URLs, so internet access is needed for those images.
4. This is a static frontend trial. Forms only show demo confirmations and do not transmit/store data.
5. Property data and reviews are demo placeholders. Replace them before publishing.
6. The WhatsApp button is set to the supplied number in international format (+91 7737210073); verify that it is registered for WhatsApp before launch.
